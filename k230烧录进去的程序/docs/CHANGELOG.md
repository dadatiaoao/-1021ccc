# 修改与验证记录

2026-10-24，按用户提供的比赛命题及补充的圆环模型含义修改。此次没有连接 K230、没有烧录 STM32、没有运行电机或舵机。

## 实际修改

1. 保留根 main.py → transport_vision/vision_app.py 的 YOLO 启动链，两个 kmodel 原样保留。
2. 将“整组带数字圆环”与“评分的最内环”区分，新增同一帧、YOLO ROI 内的局部圆族中心候选模块；无可靠几何候选时精定位模式明确失败。
3. 新增连续新帧稳定窗、过期帧拒绝、相同目标歧义处理、工位 ROI 及抓取窗口候选。
4. 收紧 PLACE_CHECK，默认未标定时不报告正确放置。不是整车动作回馈，也不能自动判断码垛成功。
5. 新增可选请求/相机姿态关联，保留基础包；推理途中任务变化时丢弃旧帧，错误命令不延后二维码超时。
6. 二维码增加连续一致性和多码歧义处理；提供纯任务展开函数验证同色码垛位置，不执行比赛任务。
7. 新增启动配置检查、模型清单及流式哈希自检、板上预览/原图采样、电脑打包及测试目录。
8. 旧 codex_yolo、codex_legacy_color、codex_gripper 原样移入 archive；夹爪异常保护和标定 JSON 均未改变。原测试从 transport_vision/tests 移至 host_tests，适配新目录。

## 已取得的软件证据

- 40 项主机测试通过，包括真实应用循环配合相机/推理/串口替身的集成场景，以及合成圆族数据、QR 和任务映射、分包及校验、配置错误场景。
- 安装工具在电脑实际检查了源目录中的模型文件，SHA256 与原文件一致，中文 manifest 使用明确 UTF-8 解码。
- 21 个当前 Python 源文件通过 CPython 语法检查；不把它作为 MicroPython 原生 API 运行通过的证据。
- 对照变更前快照，主控 User 源码、两个原模型、归档夹爪文件共 100 个受保护文件内容不变，三个旧实验目录也已逐文件比较内容一致。
- 发布工具采用白名单，排除历史实验、夹爪、电脑测试和磁盘系统目录；发布时检查 ZIP 完整性及每个成员的 SHA256。

验证日志、变更前完整视觉目录快照位于工作区 output/k230_vision_improved_2026-10-24，不放入 SD 发布包。较早的分析报告和发布 ZIP 保留为历史版本，以本目录 README 和本次发布包为准。
