| 陀螺 SDA | I2C1 PB7，J7-31 | AF4、开漏 |
| 触摸 | I2C2 PH4/PH5；PD11 RESET、PD13 INT | 沿用野火 BSP；EXTI 只通知，前台处理触摸 |
| Flash | SPI5 PF7/PF8/PF9、PF6 CS | 保留现有 BSP |
| 显示/显存 | LTDC、FMC/SDRAM、DMA2D | 保留原板资源；完整网络以 V1 原理图及 BSP 为准 |

HAL UART MSP 按 USART1/UART5/USART3 分支；统一回调位于 `User/usart/bsp_uart_callbacks.c`。UART5/USART3 各自 RX DMA 缓冲 256 字节、软件队列 512 槽，UART5 TX 持久缓冲 128 字节。光流 SPI2 初始化转发已移除，当前固件不配置其引脚；陀螺与触摸不共用 I2C 总线。

### 3.2 模块接线边界

- **电机 TTL：**主控 TX → 电机 R/A/H，主控 RX ← 电机 T/B/L，共地。光耦脉冲端和 TTL 通信端是不同接口。七台的实际参数、并联接法和电平尚未整体验证。
- **扫码：**用户已确认上述接口/模式/格式可稳定工作。裸 XM1605 资料的 12Pin 为 2=VCC、3/8=GND、4=RX、5=TX、12=TRIG；不能套用成任何转接板的排针顺序。当前固定波形用于手动电平触发；连续模式下 TRIG 的暂停/继续语义不同。实物电源/转接电路细节尚无完整记录。
- **历史光流接线（驱动未编译）：**方案使用 3.3 V 供电/逻辑，共地；模块 VCC 直接关联 VDDIO，不能因有稳压器就按 5 V 接入。资料的 MIS/MOS 丝印与信号方向有歧义：必须按芯片 MOSI 输入接 PC3、MISO 输出接 PC2，不能只看缩写。RESET 不接 MCU、依赖模块上拉及软件复位；MOTION、VREG 不接，VREG 不是外部供电口。早期有安装与模块实测记录，2026-10-24 后续反馈为模块故障；尚无恢复正常确认。实际排针版本/信号核验记录和毫米标定另待补齐，且不再作为当前底盘启动条件。
- **陀螺：**型号 WDS601M-ICM-42688，资料目标芯片 ICM-42688-P，MODULE。用户确认引脚为 **VCC、GND、SCL、SDA、SA0、CS、INT1、INT2**。当前实现走芯片直连 I2C：VCC=3.3 V，CS 拉高，SA0 拉低选 0x68，INT1/INT2 不接 MCU。PS/模式焊点按模块资料保持开路，SCL/SDA 外部上拉到 3.3 V；用户已完成实测，但具体模式焊点、上拉、电平和固定安装方向没有逐项记录。若 SA0 确认固定高，需明确改为 0x69，代码不自动猜地址。未使用板载 MCU 的串口/解算接口。

核心板供电与屏幕排线的历史事实：原画板曾由 DAP LINK 下载并正常显示/触控；屏幕产品资料为 4.3 寸、480×272、5 点触摸、RGB888，要求 5 V 与 3.3 V。原图仅作规格记录，标称刷新指标不是当前应用性能：

### 4.1 上电与屏幕操作

1. 初始化通信、扫码、gyro 和显示用限位后，进入“运行总览”。首页展示准备/机构回零/底盘验收/运动/停车/故障等真实软件阶段、当前轴或验收段号及任务码。默认 TRIAL=1 等待七机反馈齐全、静止且无故障/未确认停车后，只自动尝试一次 6→5→7 串行碰撞回零及完整停放；TRIAL=0 的内置配置仍未标定，会拒绝回零。限位去抖状态不参与开始条件。
2. 首页六个白色模块卡片分别为电机、陀螺仪、扫码、鼠标位移模块、视觉、机械臂。鼠标位移模块显示 NOT LINKED，点击留在首页，暂不设计内页；其余卡片点击进入模块；右上角 MORE/LESS 统一切换诊断。视觉页明确显示 K230 协议尚未实现。
3. 底栏在所有页面固定为“首页 / 底盘 / 机械臂 / 限位 / 停止”。底盘显示后台轮端里程计当前连续坐标段的 X/Y/YAW，断链重建用 SEG 区分；无效或过期显示 --。该估计不等于实际地面位置，也不等于每段动作的相对目标坐标。
4. 机械臂概览显示 5 号角度、6/7 号毫米位置和 HOMED/NO ZERO。MORE 内可切换轴并执行重新回零/机构验收。限位页独立显示 PG2/PG3 原始电平和消抖状态，高电平写“按下 / 断路”，7 号明确无开关。
5. 电机页只读：七轴状态、速度、单轴位置、错误/停止信息和上一轴/下一轴；已删除 MANUAL、使能/速度/脉冲 RUN、0xAA/SYNC 测试模板及隐藏标题跳转。底层 MotorBus 的运动 API 和停车策略保留。
6. 底盘 → MORE 提供“前进30cm”“后退30cm”。每次按下分别以动作开始时的车体局部 X 轴为基准，前进目标为 +300 mm、后退目标为 −300 mm；两按钮的实测前后方向已由用户于 2026-11-05 确认，自动准备四轮、使用轮端里程计和 gyro 保向，到位后确认停车并复查误差。一次点击只移动一次，不自动往返；准备/运动/停车确认期间再次点击拒绝，长按不重复。正常陀螺模式需先静止 CAL，配置和反馈有效（启动失败降级模式见末节）；停止或故障会取消尚未执行的移动。八段路线、段号、段间等待及专用接口已彻底删除。机构与底盘继续互斥，CAL/ZERO 都在机构或底盘持有控制权时拒绝；CAL 另查七轴活动/UNKNOWN/未确认 STOP，ZERO 未执行这层电机状态检查；光流采样及清零入口已移除。
7. 所有按钮为白底黑字白色矩形，按住不重复。切页只改变显示，后台采样、回零/验收继续推进；“停止”取消机构/底盘动作和运行中的比赛框架，向七轴发 STOP 并等待反馈确认，同时关闭两路舵机 PWM、取消其上电自动启用。

**比赛目标流程（需求；自动回零与纯调度已实现，通信及真实执行尚未接入）：**

- K230 发送配置就绪消息，包含抽签启停区 1/2 和初始朝向；STM32 完成自动回零、配置接收及必要准备后报告执行就绪。文档分别称为 `K230_READY` 和 `STM32_READY`，仅用于区分方向，实际协议编码待定。
- K230 先确认 STM32 的 READY，再允许板上按钮发送 START；STM32 收到后再次核查，未就绪则拒绝并回报原因。初始朝向的单位/参考方向仍需约定。
- STM32 管整场步骤，在需要视觉时发送阶段和任务代码；K230 返回对应任务的识别结果。首版不做比赛中 K230 断连/重启恢复。
- 抓住、放入载物位及释放不增加物料结果反馈，动作序列正常结束后更新逻辑槽位与计数；不把电机命令刚入队当作整个动作结束。规划首版不做抓取失败检测/重试或专用空载对心超时恢复。现有纯调度框架仍有扫码 15 s、其余每个动作 90 s 的通用超时；超时进入 FAULT 并调用停止接口，接入对心执行器前须协调这一实现与需求。超时不等于已对心成功。
- 空载对心成功后底盘保持不动，回车取料再返回记录姿态并垂直放置。原有电机反馈、停车确认/重试与故障门控继续保留；上述简化不改变当前底层代码。

| 配置 | 默认值与实际含义 |
|---|---|
| CHASSIS_MECHANICAL_CONFIRMED / CHASSIS_FEEDBACK_CONFIRMED | 当前均为 1，沿用用户调参配置；前者确认机械/方向，后者确认电机位置换算与 gyro；不再确认光流参数。源码有效配置不等于实机精度验收通过 |
| MOTOR_SYNC_CLEAN_BOOT_CONFIRMED | 0；同步缓存默认锁定，无已实测的运行期解锁方案 |
| MOTOR_DRIVER_REQUIRE_MANUAL | 0；驱动 API 不强制 UI 会话，程序化调用方负责明确动作意图；屏幕无原始电机运动入口 |
| MOTOR_UNKNOWN_AUTO_RECOVER_MS | 500；只有无未确认停止意图、获得新的零速/无故障反馈并满足稳定窗，才允许 UNKNOWN 自愈 |

除 CHASSIS_* 外，表中总线策略宏集中在 `User/motor/motor_test_config.h`（历史文件名保留）。旧 UI 测试模板及其无用宏已删除；公共 API 仍检查反馈、动作参数、目标/脉冲关系及同步锁。

### 4.2 电机通信与停止语义

已支持单轴使能、限时速度、三种位置脉冲模式（相对上一输入目标、相对坐标零点、相对当前实际位置）、四轮 37 字节 0xAA 速度聚合、传统缓存同步及逐轴反馈。不是七台实物已经同步验证。上一次输入目标不明时拒绝对应相对模式；同步缓存失败会锁定，MCU 复位不证明电机缓存已清。

总线只有一个活动请求；最小命令间隔 10 ms、应答期限 60 ms、取消/超时隔离 120 ms。静止时位置/速度/状态目标各约 500 ms；运动时速度和位置目标 200 ms、状态 500 ms，实际频率受控制、重试和离线节点影响，四轮速度发布仍为 100 ms。电机反馈新鲜度阈值保留 1600 ms，各字段独立计时。轮端位移先对齐到共同时间再使用，位置过期、跳变或断轨中止平移动作。

**2026-10-22 已落地的故障修复：**

- UART5 在清 IDLE 前检查 PE/FE/NE/ORE，DMA 回调同样隔离；恢复丢弃受影响的 DMA、软件队列及协议半帧。检查本次 RX/TX DMA 启动状态，覆盖旧 HAL 返回 OK 但底层未启动的情况。恢复失败至少间隔 100 ms；RX 错误不主动截断在途 TX。
- RX 不可用时阻止所有 TX（包括 STOP），停止意图保留，接收恢复后继续；当前没有 TX-only 停止通道。
- STOP 的“待发送”“已提交”“未确认”“已确认”分开。首次提交及两次快速尝试至少间隔 200 ms，此后至少 1000 ms 一次，轮转轴并让出反馈事务；忙/隔离会延后实际发送。
- 重复 STOP 合并，不重置首次期限或证据基准。只有首次 STOP 提交后新取得、仍新鲜的零速和无保护/堵转状态，才确认停止。ACK、DMA 完成、旧零速均不够。
- 3 s 到期可转 UNKNOWN，但保持 STOP UNCONF、运动禁入及重试；界面概览 STOP?、详情 STOP UNCONF。收到足够停车证据后停止重发。位置/速度动作本身不自动重放。
- STOP 不自动 Disable，尤其地址 6 不用失能替代升降停车。实物保持力矩与机械制动效果尚未验收。

协议线上没有事务序号，超过隔离期的同地址同码迟到响应仍有归属限制。链路断开、MCU 停机或重启时，软件不能保证机械停住；重启也不保留 RAM 中的未决意图。现有单机及双节点顺序 move 实测不覆盖这些故障情形。

### 4.3 扫码

接受固定 15 字符 `ddd+ddd+ddd+ddd`，按 CR/LF/CRLF 组帧。两批颜色各取 1～6 且不重复、集合相同；每批位置为 1～3 的排列；不从噪声里截取合法片段。用户已确认实物设置匹配且可稳定扫码。

每会话只发布并锁定一个合法任务；重复/其它码不替换。RESCAN 清当前结果、本机旧缓冲并增加会话，保留累计统计/历史；重扫等待结束符或 250 ms 无数据间隙重新同步，边界处可能丢弃首条记录。10 秒 WAIT TIMEOUT 后仍接收，静默不判离线。UART/溢出/半帧超时丢弃受损记录，不覆盖已锁定结果。

PB12 周期触发在锁定后仍继续；只更新 DUP/IGN 等统计。扫码、RESCAN、切页及故障恢复均不触发电机动作。纯文本接口不能完全识别模组内部滞留后才输出的旧码。

### 4.5 陀螺仪

仅输出选定旋转轴的 **角速度（deg/s）＋相对转角（deg）**。默认 Z+、地址 0x68、±500 °/s、100 Hz、65.5 LSB/(°/s)，这些是源码默认，非实物安装结论。使用条件为所选轴近似竖直、车体近似平面运动；相对积分会漂移，不是绝对航向或任意姿态欧拉 yaw。

驱动核验 WHO_AM_I=0x47；轮询 DRDY，只有新样本参与积分。未启用加速度业务、温度、FIFO、磁场参考或姿态融合；时间戳来自 MCU 毫秒时钟，漏样无法追回。

- **按键采样校准（2026-11-05）：**已删除固定 15.86°/s 补偿。上电显示 UNCAL / CAL REQUIRED，只提供 RAW，RATE/REL 为 `--`；等机构回零和所有运动结束，将整车保持静止，进入首页“陀螺仪”页点“校准”（CAL）。程序收集至少 201 个连续新样本且采样窗口满 2 s，成功显示 CAL:OK / READY，按本次所选轴均值更新 RAM 中的 BIAS，并将相对角归零。按住不重复；再次点击会重新测量并替换偏置。
- **零偏范围与质量检查：**为容纳现有模块约 15.86°/s 的静止读数，X/Y/Z 三轴均使用单样本绝对值 ≤25°/s、均值绝对值 ≤25°/s。三轴窗口极差 ≤1°/s、方差 ≤0.04 (°/s)²、3 s 超时及原采样连续性门限保持不变。这些是待实板验证的软件接纳上限，不是固定补偿值或传感器精度指标。窗口失败不覆盖旧偏置，并中断角度连续性；首次失败仍未校准。偏置不存 Flash，不后台自适应。
- CAL 使用当前时间的新鲜度：运动为 MOTOR ACTIVE，相关反馈不足为 MOTOR UNKNOWN，未确认停车为 STOP UNCONF。轴范围默认 0x7F；从未发现且从未命令的节点可缺省，任何轴未确认 STOP 都不能绕过。旧上电测试已删除；显式底盘准备/运动/未确认 STOP 仍阻断校准。
- ZERO 在已校准且最新样本可用、未进行 CAL 时建立新角段，保留偏置。每次上电或传感器重新初始化后必须先 CAL，ZERO 不能替代零偏校准。ZERO 只重置角段，不验证偏置，也不消除持续漂移。应用仅检查机构/底盘是否占用；`Gyro_ZeroAngle` 本身不接收电机活动或 STOP 状态，因此不能宣称 ZERO 与 CAL 具有相同的停车门控。
- 轮询空档达到 10 ms、样本 dt 大于 14 ms/为零、过期 30 ms、非法码/饱和或总线故障会中断连续性，显示 REL -- / GAP。保留旧数值供快照诊断，但不当作有效角或跨空档积分。速率恢复后可 ZERO，或重新 CAL。
- 配置巡检不更新采样 `last_poll`，避免占用下一次 DRDY 轮询额度；2026-11-04 修复切页相位下 15 ms 间隔触发 GAP 的问题。普通页第六行在异常时显示 ERR/BUS，ZERO/CAL 被机构或底盘占用拒绝时直接提示；MORE 的 LBUS 保留最近一次非 OK 的总线错误，正常通信后仍可追溯。详见 [UI 修复记录](Doc/UI_REDESIGN_2026-10-24.md)。
- 总线故障按 250 ms 至 4 s 退避；持续 500 ms 无有效样本会重初始化。电机零速与低方差不能证明没有外力推动或恒定慢转，CAL 仍要求操作者保证静止。

### 4.6 界面与主循环

全部页面共用可取消绘图状态机：一次至多绘制一个 480×4 矩形条带或两个字形后返回主循环。至少间隔 100 ms 请求新快照，冻结整组控件文本，切页立即取消旧绘图作业。仅重绘变化的控件；校准/清零依靠状态更新，不强制整页清除。

LCD 基础绘图按 180° 映射像素、线、矩形、字体及位图；触摸在 QrUi_Touch 只转换一次为 `(479-x,271-y)`。配置统一在 `User/lcd/lcd_orientation.h`。中文标签使用片内 20×20 精简字模，不依赖外部 SPI Flash 字库；英文遥测沿用 Font16，任务码使用 Font24。当前字高不代表已满足比赛 12 mm 实测要求。

这是已实现的调度策略，不是实板耗时保证。单个 LCD/HAL 操作真正超预算时仍应显示 GAP，没有调宽陀螺 10/14/30 ms 阈值来掩盖丢样。诊断包括 UI 最大单步耗时及 gyro 最大轮询/样本间隔。

## 2026-11-06：陀螺启动失败降级与纠偏

上电等待最多 2 s 检测有效陀螺原始样本；一直无可用样本时锁定本次上电为 `ENCODER ONLY / NO GYRO`。已有正常样本但尚未 CAL 时不会降级，仍须静止校准；正常启动后在运行中掉线仍按原逻辑停车。降级后底盘不采用陀螺数据，即使后台驱动重试恢复也不自动切回；重启重新检测。陀螺页保留真实错误，不伪造校准成功。

轮端模式采用四轮累计编码器位置，在共同时间点插值后计算平移和转角，正角为俯视逆时针。左右转按钮分别请求 +90/-90°；保留车体控制限速、稳定窗口、停车确认和最终误差复查。电机闭环保证轮端执行，不能保证轮胎不打滑或整车真实航向；屏幕角度是几何估算，不是陀螺实测。轮端过期、重置、跳变仍中止动作。

`User/chassis/chassis_config.h` 的 `CHASSIS_LEFT_TRAVEL_SCALE`（地址 1/3）与 `CHASSIS_RIGHT_TRAVEL_SCALE`（地址 2/4）默认均为 1.0，定义为实际有效轮周长/标称周长。比例越大，相同目标速度所需 RPM 越低；里程计使用同一比例乘回实际距离，避免只改指令而估算自相矛盾。范围 0.5～1.5；修改后重新编译上电，不允许运动中改参。这不是自动纠偏，也不能补偿随机打滑。

实测时保持地面、载荷和速度一致，记录实际直行距离、偏左/偏右、横向偏移、终点朝向角；分别测前进、后退多次。再据数据估计左右比例；仅一次横移量不足以唯一确定轮径差。转弯精度还受轮距、轴距及麦轮侧滑影响。
