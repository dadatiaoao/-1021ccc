## 4. 接线与资源选择

### 模块引脚核对表

| 已确认标识 / 资料编号 | 接口含义与接入要求 |
|---|---|
| VCC / GND，Pin1 / Pin2 | 图片标称模块供电 3～5 V；本阶段采用 3.3 V 供电方案并共地，不据此推断信号脚耐受 5 V。 |
| SCL，Pin3 | 芯片 I2C SCL / SPI SCLK；首选 I2C 接入时接所选硬件 I2C 的 SCL。 |
| SDA，Pin4 | 芯片 I2C SDA / SPI 数据输入或双向数据；首选 I2C 接入时接 SDA，核对上拉。 |
| SA0，Pin5 | 芯片 I2C 地址选择 / SPI SDO。I2C 首选固定为低得到 0x68，若板载配置为高则使用 0x69；不得悬空，也不能在未检查已有连接前强行短接。 |
| CS，Pin6 | 芯片 SPI 片选；I2C 下保持有效的高电平，与 PS 模式选择分开，不悬空、不由其它设备片选控制。 |
| INT1 / INT2，Pin7 / Pin8 | 芯片中断引脚，不是初始化输入。首版不需要 DRDY 外接时不必占 MCU 引脚；仍按芯片配置处理 INT2 的复用及电平，不能笼统短接或向输出脚强驱动。 |

另检查资料中的 PS（Pin9）或右下角模式焊点：按图片设置为芯片直连模式。PS 的“悬空”要求只用于该模块模式选择，不能扩展为 SA0/CS 也可悬空。若实际仅提供上述 8 脚，应检查模式焊盘或板卡版本，而非虚构第 9 脚接线。MCU 侧 Pin10 INT、Pin11 TX/DA、Pin12 RX/CL 不能与本表芯片侧接口混用；不要让板载 MCU 与 F429 在错误模式下同时访问芯片。

实施完成必须给出模块丝印→MCU GPIO→**V1 核心板排针脚号**→方向/配置/电平的接线表，并注明证据。没有核实的 MCU 接线不得写成已确定事实。

优先评估一组未占用、已引出的独立硬件 I2C，先以 100 kHz 联调、必要时验证到 400 kHz。优先保证触摸与光流不受影响；若没有合适空闲引脚，再说明其它方案的实际改动，不为了复用而先改写整个总线层。首版只实现一种选定接口，不同时维护两套 I2C/SPI 驱动。

## 6. 初始化、采样与相对转角

### 初始化和采样

1. 先确认模块 PS/焊盘为芯片直连模式；完成供电稳定、身份检查、软件复位及完成确认、寄存器 bank 选择、量程/ODR/滤波配置、陀螺仪启用和稳定等待，再允许发布样本；关键配置读回核对。全 0/FF 或错误 ID 不继续正常流程，不能改用另一侧 MCU 地址/协议掩盖模式错误。
2. 配置遵守所选版本的保留位、bank、接口模式及启动时序。手册中的“至少保持开启 45 ms”与“开启后 200 μs 内不写寄存器”是不同约束，不能把前者当作唯一启动条件；另核查启动就绪和首样本条件。[依据：TDK 手册 PWR_MGMT0](https://product.tdk.cn/system/files/dam/doc/product/sensor/mortion-inertial/imu/data_sheet/ds-000347-icm-42688-p-v1.6.pdf)。
3. 建议起点：陀螺低噪声工作、±500 °/s、100 Hz ODR、UI 10 Hz；这些是设计初值，不是实测保证。滤波参数须与 ODR 合法匹配，记录延迟；无需启用 DMP/APEX 或高分辨率 FIFO。
4. 从连贯样本组装有符号数据，明确字节序、所用输出格式和对应灵敏度。量程变化与换算系数必须同步，不混用普通寄存器与 FIFO 格式。验证边界、饱和及特殊无效值语义，不以裸字节全零判断静止样本非法。
5. 只有新的 data-ready 样本才能进入校准和积分；值与上一帧相同也可能是合法新样本，不能靠数值变化判断新鲜度。正确处理状态位清除规则和跨更新读取一致性。
6. 样本时间尽量靠近采集/DRDY；说明采用的是传感器时间还是 MCU 获取时间及误差。不能用 UI 刷新周期积分，也不能主循环每次调用就重复积分旧数据。
7. 报告实际采样周期、最长间隔、处理耗时和迟到情况。无 FIFO 时错过的帧不可恢复，不循环读同一最新寄存器伪造补采；若现有显示/触摸导致持续漏采，要调整调度或做必要缓冲，并保留证据。
8. 长等待及重试用状态机；每次调用限制事务数量，禁止 HAL_MAX_DELAY、长期忙等和中断绘图。使用已有时基时不得复位 DWT 或重配 SysTick，避免破坏光流计时。

### 静止零偏校准

- 默认上电完成识别后显示 UNCAL，等待显式 CAL 操作。**不能在四轮上电测试运行期间自动把转动平均成零偏。** 校准期间保持车体和模块静止；读取电机活动状态作为拒绝条件只能是辅助，电机停止不证明传感器静止。
- 建议以连续约 2 秒、满足预期样本数的窗口作为初值；窗口内数据必须新鲜、无丢样/饱和，均值和波动在可解释的限值内。阈值集中配置并标明待实测，不随意写“保证静止”。
- 用户明确保证静止，程序再检查波动与合理幅值。仅单轴陀螺无法可靠区分恒定慢转和偏置，不能宣称通过方差检查就证明没有运动。
- 校准过程中不发布有效相对转角、不触发电机；失败报告 MOVING/TIMEOUT/ERROR，不能用不完整窗口更新零偏。若有旧零偏则保留并注明本次失败，角度连续性另行失效，避免悄悄回到旧轨迹。
- 成功后设置本次零偏、相对角归零并建立新的积分基准。零偏首版仅保存在 RAM；不为本阶段增加 Flash 持久化。重新复位/重初始化后先回到待校准状态。
- 不在运行时无条件滑动修正零偏，不用死区把真实慢转长期吞掉。温度变化导致的漂移记录实测，首版不扩展温度补偿模型。

### 相对转角与清零

对安装映射后的角速度使用一致符号与单位：`ω = sign × (raw / sensitivity − bias)`；bias 必须在同一轴/单位约定下计算。相邻有效样本可用梯形积分：`Δθ = (ω_prev + ω_now) / 2 × dt_seconds`。

- 首样本只建立时间基准；不得从开机至首样本累计虚构转角。dt 用实际可解释时间并正确处理回绕。
- 内部保留连续累计角；UI 优先显示连续相对角，跨 ±180°/360°不跳变。若另提供归一化角，明确区间且不能覆盖连续积分状态。
- `ZERO` 只重建相对角基准，不重新估计偏置，不修改光流累计/扫码结果/电机模式。校准未成功或样本过期时拒绝 ZERO，并提示先校准/恢复；以最新有效样本定义清零边界。
- 无数据、读取失败、饱和、过大 dt 或已知漏采导致 ANGLE GAP：停止跨缺口积分，保留旧角作失效诊断，不用旧速率乘整段断连时间补齐。连续性失效应锁存；后续角速度恢复也不能自动声称旧角有效，需用户 ZERO 建立新段或重新 CAL。
- 传感器复位/重新配置、轴/符号/量程改变时废弃旧时间基准，按需要重校准；不能将两套尺度或方向的角度无提示拼接。
