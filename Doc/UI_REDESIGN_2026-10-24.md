## 当前界面

开机进入“运行总览”。上部为真实软件运行阶段及任务码，六个模块卡片显示电机、陀螺仪、扫码、鼠标位移模块、视觉和机械臂。鼠标位移模块显示 NOT LINKED，点击仍留在首页，不设计内页、不初始化或采样硬件。回零显示当前轴号，底盘显示运动状态，不再显示八段段号；停车/故障优先展示。比赛纯调度已接入主循环但执行端为空，K230 协议未实现；比赛页明确显示 `FRAMEWORK ONLY / NO EXECUTOR`，不能启动实车比赛。

所有页面底栏固定为 **首页 / 底盘 / 机械臂 / 限位 / 停止**。模块右上角 **MORE / LESS** 切换详情；无隐藏标题跳转。所有可点击控件均为白色矩形、黑字，背景黑色；动作只在按下边沿触发，按住或滑入按钮不重复触发。

2026-11-05 方向核对：前进按钮调用 `Chassis_StartStraightMove(...,+300.0f,...)`，后退调用 `-300.0f`，沿动作开始时的车体局部 X 轴执行。用户确认实测前后方向正确；该确认不扩展为距离精度或保向稳定性通过。

电机页删除 MANUAL、原始使能/速度/脉冲 RUN、四轮 0xAA/SYNC 测试模板和单轴/四轮分散停车入口。固定底栏“停止”统一取消机构/底盘动作及运行中的比赛框架，向七轴请求停车并等待反馈确认，同时关闭两路舵机 PWM、取消待执行的自动启用。MotorBus API、反馈校验、控制权互斥、gyro 校准门控和 STOP 重试策略继续保留。

`MECHANISM_TRIAL_RUN=1` 仍是当前默认。改版没有关闭或重启原上电回零入口（当前为 6→5→配置有效且反馈健康的 7）；首页/机构页标记 TRIAL。机械参数及其假设以 [mechanism_config.h](../User/mechanism/mechanism_config.h) 为准；5/6 回零方向及旋转臂减速比已有用户确认，2026-10-26 用户已实机确认全部 1～7 号电机均为 3200 指令脉冲/电机圈、6 号为 20 齿 × 2 mm＝40 mm/圈；真实底部余量仍未验证，不能把 TRIAL 视为整机标定完成。机构回零/验收和底盘单次直线移动继续受既有配置与反馈条件约束，切页只改显示。

舵机初始化成功后先保持 PWM 关闭；HOME 成功且三轴 HOMED、控制权与总线空闲、无待确认停车时才自动启用初始脉宽。缺少 7 轴不会自动启用。回零等待/忙/停车时 ON 和目标调整被拒绝，OFF 仍可执行；手动 ON 不要求三轴 HOMED。STOP/回零失败取消本次自动启用，后续 HOME 不会重新安排自动启用。CAL/ZERO 均检查机构/底盘控制权，只有 CAL 额外检查电机活动/UNKNOWN/未确认 STOP。

## 倒置与位置含义

- `User/lcd/lcd_orientation.h` 统一定义 `LCD_MOUNT_ROTATE_180=1`。像素、文字、线、矩形、位图在绘图底层旋转 180°，无需整屏复制或额外帧缓冲；矩形先裁剪再映射。
- 触摸驱动保留原始面板坐标；`QrUi_Touch` 转换一次为 `(479-x,271-y)`，再进行点击判定。画面与触摸不能各自重复旋转。
- 底盘展示 `Chassis.odometry` 当前连续坐标段，不是每段动作起点重置的 `data.x_mm/y_mm`。原始里程计在断链后会重新建立坐标段，页面展示 SEG 代数；无效/过期坐标显示 `--`，不能把轮端估计当成真实地面位置，打滑仍不可观测。
- 机械臂必须存在对应参考零点且位置反馈新鲜/在线才显示单位坐标。5/6 号为限位回零，7 号为碰撞回零后建立的中点 HOMED；无零点显示 `--`。7 号过程显示 COLLISION HOME / CENTERING，参数及待验状态见[机构标定记录](MECHANISM_CALIBRATION_TODO_2026-10-25.md)。
- NC 限位高电平显示“按下 / 断路”，未完成消抖显示“采样待稳定”。此接线无法仅靠高电平区分按下和断线。
- 陀螺仪上电/重新初始化后显示 UNCAL / CAL REQUIRED，RATE/REL 为 `--`。静止按“校准”（CAL）采集至少 201 个新样本、满 2 s 后更新偏置，显示 CAL:OK / READY，角度归零；RAW/BIAS 显示原始速率和本次测得偏置。已移除固定补偿及 `BIAS:FIXED` 提示。ZERO 只清角度，不重测偏置。

## 渲染和源码整理

所有页面由 `User/app/qr_ui.c` 统一生成冻结控件快照，按变化控件刷新。每次主循环最多绘制一个 480×4 条带或两个字形；普通刷新至少间隔 100 ms，切页取消未完成作业。中文字模为片内 20×20 精简子集（177 字，约 11 KiB），英文沿用 Font16，扫码大字为 Font24，不依赖外部 SPI 字库。为兼容 AC5 的旧源码字符集，qr_ui.c 使用 GBK 注释及 UTF-8 字节转义字符串，注释保留可读中文。

### 2026-11-04 gyro 调度与诊断修复

`last_poll` 仅在准备执行 `Icm_Fetch` 时更新；250 ms 配置巡检没有读取 DRDY，不再消耗下一次采样的 2 ms 轮询额度。继续保留 10 ms 轮询空档、14 ms 样本间隔、30 ms 新鲜度保护，以及 GAP 后需显式 ZERO/CAL 建立新角段的行为。

陀螺普通页第六行正常时显示 DT/AGE，初始化时显示 INIT，异常时显示 ERR 和当前 BUS（OK/NACK/TIMEOUT/BUSY/IO）。该行位于动作按钮上方，不新增第七行而与按钮重叠。ZERO/CAL 因机构或底盘占用被拒绝时，同一行显示 `ZERO/CAL REJECT: MECHANISM/CHASSIS BUSY`；ZERO 因数据或校准状态不满足也会提示。操作拒绝提示优先于该行诊断，下一次 CAL/ZERO 操作或切页清除；MORE 仍可查看诊断。按键只请求下一次控件快照刷新，不强制整页清屏。

MORE 的 LAST 表示最近一次传感器/连续性故障，LBUS 是最近一次非 OK 的 I2C 错误，成功通信或自动重初始化后仍保留；两者各自记录，未必来自同一次故障。重新初始化整个应用时清零。
