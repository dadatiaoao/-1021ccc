# 软件 I²C 可用性测试

分支 `debug/gyro-soft-i2c`，从 `main@f75e0ca` 创建。

保持接线：PB6→SCL，PB7→SDA，共地，模块使用原有3.3V供电与上拉；
CS=3.3V，SA0=GND，PS悬空。I2C1保持禁用，PB6/PB7使用开漏GPIO。
时钟半周期10us，实际频率因GPIO开销与中断略低于50kHz。

编译并烧录后打开陀螺仪页面即可，无需校准。启动等待50ms，然后每10ms
尝试读取一次0x75；只有读到0x47才计入OK。不会写传感器寄存器、软复位、
配置或输出角速度/角度。校准和清零按钮在此测试中不产生有效动作。

- OK / TOTAL：正确身份数 / 读取尝试数。
- ERROR / BADID：全部失败数 / 读操作成功但身份值错误的次数。
- NACK / TIMEOUT：没有应答 / 等待SCL实际变高超时。
- BUSY：启动时线路不空闲，或发送1时SDA实际为0等总线冲突情况。
- LAST：最近一次失败的总线结果；若BADID增加且LAST=OK，表示事务返回成功但数据错误。

失败后仍继续定期尝试。NACK后尝试STOP，超时或疑似仲裁冲突只释放线路；
不做9脉冲解锁、不重置I2C外设、不自动重置计数。BUSY可能是一次故障后的
后续尝试，不能把全部BUSY都当成独立的线上事务错误。

分别测试同时上电、模块先上电、仅复位STM32。每次观察约2分钟（TOTAL至少10000），
拍下计数，正常目标是OK=TOTAL且ERROR=0。Reset重新开始计数。
通过只说明软件I²C身份读取可用，不代表传感器完整配置/采样已验证。

仅进行了源代码编译/语法检查，未增加新测试套件；仍需Keil构建及实际板卡验证。
