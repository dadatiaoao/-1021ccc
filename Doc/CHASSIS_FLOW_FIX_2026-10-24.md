# 首次试跑 FLOW INVALID：证据、修复与标定记录

日期：2026-10-24。修复基线：`d0f5e86`，底盘初版代码为 `f9ec56f`。

**实机结果：用户报告小车前进少许后停止，第一段失败；没有完成八段或精度验收。软件已复现并修复一个时间配对缺陷，待补齐 Y 标定并重新实机验证。** 本轮没有烧录或操控实车。

## 1. 用户提供的实机证据

照片显示：`FAULT FAILED`、`1/8 FORWARD`、目标 `(300,0,0)`、当前 `X:-- Y:-- A:4`、输出速度为零、`FLOW:OK GYRO:OK STOP:OK`、`TX:37 REJ:0 AGE:451`，失败原因为 `FLOW INVALID`。角度 4° 是程序显示值，没有外部角度参考；TX 是总线累计统计，不能据此推定本次运行时长。

用户随后提供 FLOW 读数：

| 项目 | 用户读数 |
|---|---|
| Q / BAD / E | 150 / 0 / 0 |
| S / G / M | 1 / 0 / 0 |
| ERR / FAULT | NONE / NONE |
| MAXdt / PROC | 10 ms / 1061 us |

这些累计计数没有显示低质量拒收、通信错误、重启或采样缺口，与下面的软件配对复现吻合。但旧固件没有锁存里程计中止细因，不能把主机复现直接写成已完成实机根因验证。

`FLOW:OK` 显示的是拍照时的当前里程计可用性；`FLOW INVALID` 保留的是已经中止的动作结果。故障后重新建立里程计基线不会自动恢复原动作，因此 X/Y 显示 `--`，而 STOP 可已经确认。这组显示不表示“前进动作成功”。

## 2. 已证明的软件缺陷

原实现每轮只尝试将最新 FlowSnapshot 与最近两个 gyro 样本配对，没有保存尚在等待后续 gyro 样本的光流快照。

复现：gyro 时间戳为 0、10、20…ms，光流为 0、15、25…ms。看到 flow=15 时最新 gyro=10，按要求应等待 gyro=20；下一次调用却只尝试新的 flow=25，从而丢弃已经能与 10/20 配对的 flow=15。相位持续错开时，两项传感器都正常，里程计仍会因超过 100 ms 没有成功配对而失效。

新增回归在旧实现上复现失败：`Output/flow-phase-before.log`，断言 `o.valid && !o.generation` 失败。

修复保留一个有界 pending FlowSnapshot，下一轮先配对旧样本，再处理新样本；可累计的连续 counts 保留，样本按序消费。没有引入角度外推，没有放宽 14 ms gyro 配对跨度、100 ms 光流时效或质量门限。真实 rejected/gaps/segments/clears/overflow、gyro 断轨仍使相关动作失败并停车。

## 3. 故障细因与屏幕诊断

- 里程计保留失效时刻、当前光流年龄、上次成功配对年龄、Q、BAD/G/S/CLR 及具体原因。
- Chassis 锁存本次动作的首次失败证据，后续实时测量恢复不覆盖；新的明确准备/动作请求才清除。
- FLOW 服务额外保留最近一次拒收的错误、Q 和时间，避免在底盘再次读取前恢复为 OK 而丢失拒收原因。采集与停车规则不变。
- 底盘失败行可显示 `FLOW INVALID: TIME ALIGN`、`LOW QUALITY`、`STALE`、`SAMPLE GAP`、`CLEARED` 等；上一行 `AT Q:... BAD:... G:... PAIR:...` 是故障时的数据，PAIR 单位 ms。当前 FLOW/GYRO/STOP 行仍表示当前状态。

## 4. 用户标定数据与配置修正

用户明确：**前后 X 方向，180 count 对应 23 mm；另一轴未测。** 这是单次、短距离标定数据，不是三次重复精度验收。

```text
X mm/count = 23 / 180 = 0.1277777778
```

原工作区 X/Y 均填写 7.826；该数值约为 `180/23`，是 count/mm，不能直接用于要求 mm/count 的参数。若用于 X，会把距离放大约 61 倍。

当前工作区修改为：

```c
#define CHASSIS_FLOW_X_MM_PER_COUNT 0.12777778f
#define CHASSIS_FLOW_Y_MM_PER_COUNT 0.0f
#define CHASSIS_FEEDBACK_CONFIRMED 0u
```

用户已录入的 D=78 mm、L=216 mm、W=218.6 mm、减速比 1、轮符号 `{1,-1,1,-1}`、机械确认=1 均保留；这些数值来自原工作区，本轮没有替用户重新测量或更改。安装角和 offset 仍保留原工作区的零值，本轮没有新增其准确性证据。gyro 固定补偿 15.86°/s 保持不变。

由于 Y 未测，**修复固件的屏幕 START 当前仍应拒绝自动验收，显示 CONFIG REQUIRED**。不能沿用 X 标定去猜测 Y，也不能只把确认标志置 1 强行通行。速度 API 的机械准备层与闭环标定层仍分开。

下一次数据：在相同地面/安装高度、电机不驱动、车头方向保持不变的条件下，记录 X/Y 累计初值，人工向左直移已知距离（例如 200 mm），再记录 X/Y 终值，至少三次。提供距离、两个轴的累计差值、Q 和 BAD/G 变化；先核对轴向及交叉轴残差，再计算 Y mm/count。gyro 漂移、偏置位置和 STOP/整轮精度仍按原标定说明核对。
