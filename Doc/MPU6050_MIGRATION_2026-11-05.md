# MPU6050 临时迁移（2026-11-05）

分支：`feat/mpu6050-migration`。已执行 `git fetch origin main`，创建时本地 main 与远端 main 均为 `f75e0ca`。旧 WDS601M / ICM-42688 模块故障，按最小改动临时换 MPU6050。已完成软件迁移和验证；尚未烧录或实板验收。

## 接线

主控仍是野火 F429，I2C1 仍为 100 kHz，未改任何 MCU GPIO 分配。按模块丝印接线，不按旧模块排针位置插接。

| MPU6050 模块引脚 | 连接 | 说明 |
|---|---|---|
| VCC | 3.3 V | 优先沿用原 3.3 V 电源；先核实该模块 VCC 输入范围与稳压压降 |
| GND | 原 GND | 与 F429 共地 |
| SCL | PB6 / J7-32 | 沿用原 SCL 线，I2C1 AF4 开漏 |
| SDA | PB7 / J7-31 | 沿用原 SDA 线，I2C1 AF4 开漏 |
| AD0（用户标注 ado） | GND | 选 7 位地址 0x68，不悬空；可沿用旧 SA0 接地线 |
| XDA | 不接 | 辅助 I2C 数据，不是主控 SDA |
| XCL | 不接 | 辅助 I2C 时钟，不是主控 SCL |
| INT | 不接 | 软件轮询 DRDY，不占用 MCU 中断脚 |

移除旧模块的 CS→3.3 V 连线；MPU6050 模块没有对应 CS。SCL/SDA 必须上拉至 3.3 V，若模块无上拉，可补约 4.7 kΩ 外部上拉；已有上拉时核实并联阻值和电平。仅凭 8 个引脚名称无法确认板载稳压器型号；不要把模块允许的 VCC 电压等同于信号允许电压。芯片 VDD 范围为 2.375～3.46 V，按实际模块电路核实芯片供电。[TDK 芯片规格](https://product.tdk.com/system/files/dam/doc/product/sensor/mortion-inertial/imu/data_sheet/mpu-6000-datasheet1.pdf)

AD0 若实物固定接高，需显式把 `GYRO_ADDRESS_7BIT` 改为 `0x69u`；代码不自动猜地址。两种地址下 WHO_AM_I 都应读到 `0x68`。J7 排针编号沿用工程中已经核对过的野火 V1 板记录；本轮没有重新修改或绘制硬件原理图。

驱动先等待 100 ms，再核验身份、执行复位并等待 100 ms，检查复位后的 `PWR_MGMT_1=0x40`，再次核验身份。配置时逐项写入/读回，最后唤醒后等待 50 ms。MPU 没有 ICM 的 RESET_DONE 位、bank/I3C 配置或负数无效码；发生复位靠配置丢失或无 DRDY 超时触发恢复。

参数为 ±500°/s、65.5 LSB/(°/s)、100 Hz（1 kHz / 10）、20 Hz DLPF；三轴陀螺开启，加速度/温度业务、FIFO、辅助主机与旁路关闭。每 250 ms 巡检一个寄存器，ID 加 9 项配置完整轮查约 2.5 s；连续 500 ms 无样本触发重建，旧 10/14/30 ms 采样连续性阈值保留。

`INT_RD_CLEAR=0` 时读 INT_STATUS 会清 DRDY。先读状态确认有新数据，再一次连续读 `0x3A..0x48` 共 15 字节（状态＋跳过的加速度/温度＋三轴 gyro），以同时消费两次事务之间到来的 DRDY，避免同一帧重复积分。一次调用最多两个 I2C 事务。依据为 [InvenSense 原厂寄存器手册 rev 4.0（SparkFun 镜像）](https://cdn.sparkfun.com/datasheets/Sensors/Accelerometers/RM-MPU-6000A.pdf) 的状态清除规则及传感器影子寄存器一致性说明；来源记录见 `User/gyro/UPSTREAM.md`。

## 上板操作

1. 按上述表断电接线并烧录 `Output/YH-F429.hex`。默认机构上电回零流程仍会运行，陀螺仪迁移没有改变它。
2. 等机构回零完成或明确停止、底盘静止后，进入首页的陀螺仪页。初始化后应显示 `UNCAL / RAW`，MORE 中身份为 `68`，RAW 随旋转变化；此时 RATE/REL 尚不可用，依赖有效角度的底盘动作会被原有门控拒绝。
3. 保持模块和整车完全静止，按 CAL，等待约 2 s、至少 201 个连续样本。成功后应显示 READY / CAL OK，静止 RATE 接近 0，REL 从 0 开始。
4. 默认 `GYRO_AXIS=2`、`GYRO_SIGN=1`（Z+），必须核对实物竖直轴与正向。手动做已知角度的左右旋转，检查符号、角度和回零误差，再测试底盘八段；换芯片后的轴向与角度精度不能沿用旧实测结论。
5. ZERO 只清相对角，不改变零偏；断电或传感器恢复重初始化后须重新 CAL。REL 是积分相对角，会漂移，不是绝对航向。

CAL 沿用原始绝对值 ≤5°/s、均值 ≤3°/s、极差 ≤1°/s、方差 ≤0.04 的门限。新 MPU 的个体零偏、温漂和静止噪声未实测，若持续 MOVING，应记录三轴原始值与波动，再判断是否需要调整；不要重新启用旧模块的 15.86°/s 补偿。
